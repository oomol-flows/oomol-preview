# OOMOL Preview

一套全面的预览组件集合，让您轻松可视化和显示各种类型的文件和数据格式。

## 什么是 OOMOL Preview？

OOMOL Preview 是一个为 OOMOL 平台提供即用型构建块（组件）的包，用于预览不同类型的内容。无论您处理的是图像、视频、音频文件、文档还是数据文件，这个包都能满足您的需求。

## 使用场景

此包非常适合：

- **内容创作者**：在发布前预览和审查媒体文件
- **数据分析师**：可视化 JSON 数据和结构化信息
- **Web 开发者**：预览 HTML 内容和 Markdown 文档
- **媒体专业人士**：审查各种格式的图像、视频和音频文件
- **文档工作流**：显示和审查 Markdown 和文本文档

## 可用组件

### 图像预览组件

#### 🖼️ 图像预览
显示单个图像文件，支持以下格式：
- PNG（便携式网络图形）
- JPEG（联合图像专家组）
- WebP（Web 图片格式）
- GIF（图形交换格式）
- AVIF（AV1 图像文件格式）
- BMP（位图图像文件）
- ICO（图标格式）
- TIFF（标记图像文件格式）

**输入**：图像文件路径
**用途**：查看来自文件系统或从 URL 下载的单个图像

#### 🖼️ 二进制图像预览
直接从二进制数据显示图像，无需先保存到磁盘。

**输入**：图像二进制数据
**用途**：预览在内存中生成或处理的图像

#### 🖼️🖼️ 图像列表预览
在图库视图中一次显示多个图像。

**输入**：图像文件路径数组
**用途**：批量审查图像、创建图像画廊或并排比较多个图像

### 视频预览

#### 🎬 视频预览
播放和预览视频文件，支持以下格式：
- MP4（MPEG-4 Part 14）
- WebM（Web 媒体）
- HLS（HTTP 直播流 - .m3u8）
- MOV（QuickTime 影片）
- Ogg 视频

**输入**：视频文件路径
**用途**：审查视频内容、检查视频质量或预览处理后的视频

### 音频预览

#### 🎵 音频预览
播放和预览音频文件，支持以下格式：
- MP3（MPEG 音频层 3）
- MP4 音频（M4A）
- WAV（波形音频文件格式）
- WebM 音频
- FLAC（无损音频编解码器）
- Opus 音频
- PCM（脉冲编码调制）
- Vorbis 音频
- AAC（高级音频编码）

**输入**：音频文件路径
**用途**：收听音频文件、审查录音或检查音频质量

### 文档和数据预览组件

#### 📄 HTML 预览
在嵌入式浏览器视图中渲染和显示 HTML 内容。

**输入**：HTML 文本内容
**用途**：预览网页、渲染的 HTML 模板或生成的报告

#### 📝 Markdown 预览
显示带有适当格式的 Markdown 文本，包括标题、列表、链接等。

**输入**：Markdown 文本内容
**用途**：预览 Markdown 文档、笔记或格式化文本

#### 📝 Markdown 文件预览
加载并显示 Markdown 文件，支持完整格式。

**输入**：Markdown 文件路径（.md、.markdown、.mdown）
**用途**：审查文档文件、README 文件或基于 Markdown 的内容

### JSON 数据预览组件

#### 📊 JSON 文件预览
显示带有语法高亮的 JSON 文件，便于阅读。

**输入**：JSON 文件路径（.json、.jsonc、.json5、.geojson）
**用途**：审查配置文件、保存为文件的 API 响应或数据导出

#### 📊 JSON 字符串预览
显示带有语法高亮的字符串形式的 JSON 内容。

**输入**：JSON 文本字符串
**用途**：预览从 API 返回或动态生成的 JSON 数据

#### 📊 JSON 对象预览
显示带有适当格式和语法高亮的 JSON 对象。

**输入**：JSON 对象数据
**用途**：检查数据结构、调试或审查处理后的数据

## 如何使用

### 在 OOMOL 工作流中

1. **添加预览包**：在您的 OOMOL 工作区中安装 `oomol-preview`
2. **拖放操作**：从库中选择合适的预览组件
3. **连接数据**：将上一个工作流步骤的输出链接到预览组件的输入
4. **运行并查看**：执行工作流以查看预览

### 示例工作流场景

**场景 1：下载并预览图像**
```
URL 输入 → 下载文件 → 图像预览
```
从互联网下载图像并立即预览。

**场景 2：处理并审查视频**
```
视频文件 → 视频处理 → 视频预览
```
对视频应用滤镜或编辑并预览结果。

**场景 3：API 数据可视化**
```
API 调用 → JSON 响应 → JSON 对象预览
```
从 API 获取数据并以可读格式显示。

**场景 4：文档审查**
```
Markdown 编辑器 → Markdown 预览
```
编写或编辑 Markdown 内容并实时查看格式化结果。
